
Doubly Linked List (DLL): A to Z Setup & Mechanics Guide

1. What is a Doubly Linked List (DLL)?

Singly Linked List: Isme har node ke paas sirf ek pointer hota hai (next). Hum sirf aage (forward) ja sakte hain, peeche mud kar nahi dekh sakte.

Doubly Linked List (DLL): Isme har node ke paas do pointers / arrows hote hain:

next (Aage ka arrow): Agle node ki taraf ishara karta hai.

prev (Peeche ka arrow): Pichle node ki taraf ishara karta hai.

Main Benefit: Dual-direction navigation aur kisi bhi node ko constant time $O(1)$ mein delete karne ki capability.

2. Node Structure (Dabbe ki Banaawat)

class Node:
    def __init__(self, key, val):
        self.key = key       # Node ki key / identifier
        self.val = val       # Node ka data / value
        self.prev = None     # Pichle node ka reference (Peeche ka arrow)
        self.next = None     # Agle node ka reference (Aage ka arrow)


3. Sentinel / Dummy Nodes Setup (self.head & self.tail)

To avoid null pointer exceptions (NoneType errors) at boundaries, we use Dummy Head and Dummy Tail nodes.

class DoublyLinkedList:
    def __init__(self):
        # Farzi (Dummy) dabbe banaye
        self.head = Node(0, 0)
        self.tail = Node(0, 0)
        
        # Shuru mein dono ko aapas mein jod diya
        self.head.next = self.tail
        self.tail.prev = self.head


4. Understanding the Arrows (Pointers)

node.next: Left to Right travel karne ke liye.

node.prev: Right to Left travel karne ke liye.

5. Insertion Example: Adding Node 2 between Node 1 and Node 3

Initial State (Before):

[ Node 1 ] <---> [ Node 3 ]

Node 1.next points to Node 3

Node 3.prev points to Node 1

Target State (After):

[ Node 1 ] <---> [ Node 2 ] <---> [ Node 3 ]

6. The 4-Step Adding Mechanics (Wiring Steps)

Golden Rule: Pehle naye node ke pointers (.next aur .prev) set karo, phir aas-paas wale purane nodes ki wiring update karo.

Step 1: Naye Node (Node 2) ka Aage ka Arrow (.next) set karo

Node2.next = Node1.next  # (Yani Node 3)


Reason: Naye node ka aage ka rasta secure kar diya taake aage ki list cut ke gayab na ho.

Step 2: Naye Node (Node 2) ka Peeche ka Arrow (.prev) set karo

Node2.prev = Node1


Reason: Naye node ko pata chal gaya ke uske piche Node 1 khada hai.

Step 3: Purane Aage Wale Node (Node 3) ka Peeche ka Arrow update karo

Node1.next.prev = Node2  # (Node 3.prev = Node 2)


Reason: Node 3 ka jo .prev pehle Node 1 par tha, usko tod kar ab naye Node 2 par laga diya.

Step 4: Purane Pichle Node (Node 1) ka Aage ka Arrow update karo

Node1.next = Node2


Reason: Node 1 ka jo .next pehle Node 3 par ja raha tha, ab usko badal kar naye Node 2 par jod diya.

7. Insertion Code Template (Adding to Front after self.head)

def add_to_front(self, node):
    # Step 1: Naye node ka next set karo
    node.next = self.head.next
    
    # Step 2: Naye node ka prev set karo
    node.prev = self.head
    
    # Step 3: Purane pehle node ka prev update karo
    self.head.next.prev = node
    
    # Step 4: Head ka next update karo
    self.head.next = node


8. Deletion Example: Removing Node 2 from the List

Initial State (Before):

[ Node 1 ] <---> [ Node 2 (to delete) ] <---> [ Node 3 ]

Target State (After):

[ Node 1 ] <---> [ Node 3 ]

9. The 2-Step Deletion Mechanics ($O(1)$ Removal)

Kyunki Node 2 ke paas apne .prev (Node 1) aur .next (Node 3) ka reference pehle se hota hai, hum bina kisi loop ke $O(1)$ time mein bypass kar dete hain:

Step 1: Pichle Node (Node 1) ka Aage ka Arrow Update Karo

node.prev.next = node.next  # (Node 1.next = Node 3)


Reason: Node 2 ke pichle node (Node 1) ko bolte hain ke apna .next ab direct Node 3 par jod do.

Step 2: Agle Node (Node 3) ka Peeche ka Arrow Update Karo

node.next.prev = node.prev  # (Node 3.prev = Node 1)


Reason: Node 2 ke agle node (Node 3) ko bolte hain ke apna .prev ab direct Node 1 par jod do.

10. Deletion Code Template

def remove_node(self, node):
    prev_node = node.prev
    next_node = node.next
    
    # Step 1: Peeche wale node ka next, aage wale node par lagao
    prev_node.next = next_node
    
    # Step 2: Aage wale node ka prev, peeche wale node par lagao
    next_node.prev = prev_node


11. Quick Summary & Rules to Remember

self. variable: self.head aur self.tail permanent class attributes hote hain, jo class ke har function mein available rehte hain.

Insertion Order: Hamesha naye node ki links pehle banao, purane node ki links baad mein update karo.

Deletion Advantage: Removal mein koi search loop nahi chalana padta, sirf node.prev.next aur node.next.prev ko bypass karna hota hai.

Time Complexity:

Insertion at head/tail: $O(1)$
