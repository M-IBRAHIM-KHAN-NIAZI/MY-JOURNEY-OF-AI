### Movement Logic Summary with Example (Valid Parentheses - LC 20) ###

**Step 0 (Understanding `s` - The Input Parameter):** 
* Function ke andar jo `s` likha hota hai (`def isValid(self, s: str):`), yeh khud se koi fixed string nahi hoti balki ek placeholder ya rasta hota hai.
* Jab hum code ke aakhir mein testing ke liye koi string pass karte hain (jaise `sol.isValid('()[]{}')`), toh woh poori data string seedha is `s` ke andar save ho jati hai.
* Ishi `s` ke zariye poora input data function ke andar aata hai jis par hamara loop chalta hai.

**Step 1 (Setup & Initialization):** 
* `stack = []`: Ek khali list banati hai jo opening brackets ko temporary taur par store karti hai.
* `mapping = {")": "(", "}": "{", "]": "["}`: Ek dictionary banati hai jo batati hai ke kis closing bracket ka kaun sa exact opening joda (partner) hai.

**Step 2 (Iterating Through String One-by-One - For Loop & Key Check):** 
* Chahe hum test mein poori brackets ki string ikatthi likh dein (jaise `()[]{}`), lekin `for char in s:` loop poori string ko ek sath check nahi karta, balki **ek-ek character karke** left se right chalta hai.
* Jab loop mein sabse pehle **opening bracket** aata hai, toh `if char in mapping:` check hota hai. Kyunki `mapping` ki **keys** mein sirf closing brackets hain, isliye opening bracket keys mein nahi milta.
* Isiliye opening bracket `mapping` ko bypass karke seedha `else` block mein jata hai aur `stack.append(char)` ho kar stack ke andar save ho jata hai.

**Step 3 (Handling Closing Brackets & Dictionary Values):** 
* Jab loop chalte-chalte aage **closing bracket** par aata hai, toh `if char in mapping:` check True ho jata hai kyunki closing brackets `mapping` ki **keys** mein maujood hote hain.
* Yahan **dictionary ki values** ka asli maqsad yeh hota hai ke yeh humein woh exact matching opening bracket (joda) la kar deti hain, jisko hum stack ke top element ke sath compare karte hain.
* `top_element = stack.pop()` karke stack ka aakhri element nikala jata hai, aur check hota hai ke kya `mapping[char] == top_element` hai? Agar barabar nahi hai, toh foran **`False`** return ho jata hai.

**Step 4 (Final Return):** 
* Jab string ke saare characters ek-ek karke check ho chuke hote hain, toh aakhir mein `return not stack` chalta hai. 
* Agar stack poori tarah khali (`[]`) ho chuka hai (yani sabke sahi jode ban kar pop ho chuke hain), toh **`True`** return hota hai, warna **`False`**.
