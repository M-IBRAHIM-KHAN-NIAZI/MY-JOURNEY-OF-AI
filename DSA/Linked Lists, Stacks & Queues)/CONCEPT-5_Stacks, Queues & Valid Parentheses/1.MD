### Movement Logic Summary with Example (Valid Parentheses - LC 20) ###

**Step 1 (Setup & Initialization):** 
* `stack = []`: Ek khali list banati hai jo opening brackets ko temporary taur par store karti hai.
* `mapping = {")": "(", "}": "{", "]": "["}`: Ek dictionary banati hai jo batati hai ke kis closing bracket ka kaun sa exact opening joda (partner) hai.

**Step 2 (Iterating through String - For Loop):** 
* `for char in s:` loop chalta hai jo input string (misal ke tor par `s = "()[]{}"`) ke har ek character ko left se right ek-ek karke uthata hai.

**Step 3 (Handling Opening Brackets - Else Block):** 
* Jab loop mein koi opening bracket (`(`, `{`, `[`) aata hai, toh `if char in mapping:` check fail ho jata hai (kyunki `mapping` ki keys mein sirf closing brackets hain). 
* Code `else` block mein jata hai aur `stack.append(char)` karke us opening bracket ko stack ke top par save kar deta hai. *(Example: `stack` ban gaya `['(']`)*.

**Step 4 (Handling Closing Brackets - If Block & Stack Pop):** 
* Jab loop mein koi closing bracket (`)`, `}`, `]`) aata hai, toh `if char in mapping:` True ho jata hai.
* `top_element = stack.pop()` chalta hai jo stack ke aakhri (top) element ko remove karke nikalta hai. (Agar stack pehle se khali ho, toh dummy value `#` use hoti hai).
* Phir check hota hai: `if mapping[char] != top_element:` agar closing bracket ka joda stack ke top element se match nahi karta, toh foran **`False`** return ho jata hai.

**Step 5 (Final Return):** 
* Jab string ke saare characters khatam ho jate hain, toh aakhir mein `return not stack` chalta hai. 
* Agar stack poori tarah khali (`[]`) ho chuka hai (yani sabke sahi jode ban kar pop ho chuke hain), toh **`True`** return hota hai, warna **`False`**.
