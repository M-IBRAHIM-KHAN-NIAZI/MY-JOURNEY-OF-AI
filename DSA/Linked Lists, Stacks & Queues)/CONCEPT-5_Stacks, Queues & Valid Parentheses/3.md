1. Reverse Polish Notation (RPN) Kya Hai? (A to Z Concept)
Normal Math (Infix): Hum aam taur par likhte hain (2 + 1) * 3. Isme operator (+, *) do numbers ke beach mein aata hai. Computer ke liye isko solve karna thoda mushkil hota hai kyunki brackets () aur BODMAS rule ka dhyan rakhna padta hai.

Reverse Polish Notation (Postfix): RPN mein operator do numbers ke baad aata hai. Jaise (2 + 1) ban jata hai 2 1 +, aur jab isko 3 ke sath multiply karna ho toh yeh ban jata hai: ["2", "1", "+", "3", "*"].

Stack ka Kamal: Isko solve karne ka sabse asaan aur duniya ka best tarika Stack hai!

Jab koi number aaye, usko stack mein chup chap daal (push) do.

Jab koi operator (+, -, *, /) aaye, toh stack se do numbers bahar nikalo (pop), un par operation perform karo, aur jo naya jawab aaye usko wapas stack mein daal do!

### Movement Logic Summary with Example (Evaluate Reverse Polish Notation - LC 150) ###

**Step 0 (Setup & Initialization):** 
* `stack = []`: Ek khali list banati hai jo numbers ko temporary taur par store karti hai jab tak calculation perform hoti hai.

**Step 1 (Iterating Through Tokens - For Loop):** 
* `for token in tokens:` loop chalta hai jo input list (misal ke tor par `tokens = ["2", "1", "+", "3", "*"]`) ke har ek element ko left se right ek-ek karke uthata hai.

**Step 2 (Handling Numbers - Else Block):** 
* Jab loop mein koi number aata hai (jaise `"2"`, `"1"`, ya `"3"`), toh yeh operator nahi hota.
* Code `else` block mein jata hai, string ko integer mein convert karta hai (`int(token)`), aur stack ke andar append kar deta hai. *(Example: `stack` ban gaya `[2, 1]`)*.

**Step 3 (Handling Operators & Popping Operands - If/Elif Blocks):** 
* Jab loop mein koi operator aata hai (jaise `+`, `-`, `*`, `/`), toh `stack.pop()` chalakar aakhri do numbers nikal liye jate hain:
  - `b = stack.pop()` (doosra number jo pehle bahar aata hai - right operand).
  - `a = stack.pop()` (pehla number jo baad mein bahar aata hai - left operand).
* Uske baad calculation hoti hai (jaise `a + b`), aur jo naya result banta hai, usko wapas stack mein daal diya jata hai. *(Example: `2 + 1 = 3` ban kar stack mein wapas chala gaya).*

**Step 4 (Final Return):** 
* Jab list ke saare tokens khatam ho jate hain, toh aakhir mein stack ke andar sirf ek hi final answer bachta hai.
* `return stack[0]` karke woh final result return ho jata hai.
