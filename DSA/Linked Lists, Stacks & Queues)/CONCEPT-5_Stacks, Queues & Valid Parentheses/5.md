### Movement Logic Summary with Example (Binary Tree Level Order Traversal - LC 102) ###

**Example Tree:** Root `3` -> left child `9`, right child `20` -> `20` ke left child `15`, right child `7` (`[[3], [9, 20], [15, 7]]`).

**Step 0 (Setup & Initialization):**
* `if not root: return []`: Agar tree hi khali hai toh seedha khali list return kar do.
* `result = []`: Ek khali list banati hai jo har level ki values ko alag list ki shakal mein final answer ke liye store karti hai.
* `queue = deque([root])`: Ek fast double-ended queue banati hai aur usmein sabse pehle `root` (`3`) ko daal deti hai.

**Step 1 (Level Loop & Level Snapshot - While/For Loop):**
* `while queue:`: Jab tak queue mein koi na koi node baaki hai, tab tak level by level loop chalta rehta hai.
* `level_size = len(queue)`: Us waqt current level mein total kitne nodes hain, yeh count karta hai taaki aage dalne wale bache is hi level mein mix na hon. *(Example: Level 1 mein `level_size = 1`, Level 2 mein `2`, Level 3 mein `2`).*
* `current_level = []`: Har level ke shuru mein ek nayi khali list banti hai jo sirf us current level ki values rakhti hai.

**Step 2 (Popping Nodes & Pushing Children - For Loop):**
* `for _ in range(level_size):`: Current level ke har node ke liye loop chalta hai.
* `node = queue.popleft()`: Queue ke aage (front) se pehla node nikalti hai (FIFO order mein).
* `current_level.append(node.val)`: Nikale gaye node ki value `current_level` list mein daal deti hai. *(Example: Level 1 mein `[3]`, Level 2 mein `[9, 20]`, Level 3 mein `[15, 7]`).*
* `if node.left: queue.append(node.left)`: Agar node ka left bacha mojood hai, toh usko agle level ke liye queue ke aakhir mein daal deti hai.
* `if node.right: queue.append(node.right)`: Agar node ka right bacha mojood hai, toh usko bhi agle level ke liye queue ke aakhir mein daal deti hai. *(Example: `3` ke baad `9` aur `20` queue mein gaye; `20` ke baad `15` aur `7` queue mein gaye).*

**Step 3 (Saving Level & Final Return):**
* `result.append(current_level)`: Ek level ke saare nodes process hone ke baad `current_level` list ko final `result` mein append kar diya jata hai.
* Jab `queue` poori tarah khali ho jati hai aur saare levels khatam ho jate hain, toh `return result` karke final 2D list (`[[3], [9, 20], [15, 7]]`) return ho jati hai.
