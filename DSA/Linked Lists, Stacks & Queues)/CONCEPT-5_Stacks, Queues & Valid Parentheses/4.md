### Movement Logic Summary with Example (Implement Queue using Stacks - LC 232) ###

**Step 0 (Class Setup & Initialization):** 
* `class MyQueue:` ek custom class banata hai jo Queue ki tarah behave karti hai.
* `def __init__(self):` constructor ke andar do stacks banaye jate hain:
  1. `self.input_stack = []`: Naye incoming elements ko receive karne ke liye main stack (Push ke liye).
  2. `self.output_stack = []`: FIFO order maintain karke pop/peek karne ke liye helper stack.

**Step 1 (Push Method):** 
* `def push(self, x: int) -> None:` jab bhi koi naya number aata hai, toh usko chup chap `self.input_stack.append(x)` kar diya jata hai. *(Example: push(10), push(20), push(30) ke baad `input_stack = [10, 20, 30]` aur `output_stack = []` ho jata hai).*

**Step 2 (The Magic _move() Helper Function - DRY Principle):** 
* `def _move(self):` ek helper function hai jo yeh check karta hai ke kya `output_stack` khali hai?
* Agar `output_stack` khali hai, toh yeh `input_stack` ke saare elements ek-ek karke pop karta hai aur `output_stack` mein push kar deta hai. Isse stack ka ulta (LIFO) order reverse ho kar bilkul sahi **FIFO (Queue)** order ban jata hai. *(Example: `input_stack = [10, 20, 30]` shift ho kar `output_stack = [30, 20, 10]` ban jata hai, jisme `10` sabse upar aa jata hai).*

**Step 3 (Pop Method - Safe Removal):** 
* `def pop(self) -> int:` sabse pehle `self._move()` ko bulata hai taaki elements sahi order mein aa jayein.
* Uske baad `self.output_stack.pop()` chalakar queue ke rule ke mutabiq sabse pehla (oldest) element bahar nikal deta hai. *(Example: `10` pop ho kar bahar aa jata hai).*

**Step 4 (Peek Method - Inspecting Front Element):** 
* `def peek(self) -> int:` yeh bhi pehle `self._move()` chalata hai aur phir bina remove kiye `self.output_stack[-1]` ke zariye samne (front) wala element dikha deta hai.

**Step 5 (Empty Check):** 
* `def empty(self) -> bool:` check karta hai ke `not self.input_stack and not self.output_stack` (yani jab dono stacks khali hon, tabhi queue empty maani jayegi).
