### Movement Logic Summary with Example (Min Stack - LC 155) ###

**Step 0 (Class Setup & Initialization - Constructor):** 
* `class MinStack:` ek blueprint banata hai jiske andar hamare saare stack ke operations aur data structures mojood hote hain.
* `def __init__(self):` constructor hai jo object banne par sabse pehle chalta hai aur do khali stacks banata hai:
  1. `self.stack = []`: Main stack jo saare incoming numbers ko normal tarike se store karta hai.
  2. `self.min_stack = []`: Helper/min stack jo har point par us waqt ka sabse chhota (minimum) number track karke rakhta hai.

**Step 1 (Push Method & Synchronization Logic):** 
* Jab hum `obj.push(val)` chalate hain, toh sabse pehle naye number ko main stack mein daal diya jata hai: `self.stack.append(val)`.
* Uske baad `min_stack` mein check hota hai: `if not self.min_stack or val <= self.min_stack[-1]:`[-1 means last current number]
  - Agar `min_stack` khali hai, ya naya number current minimum se chota/barabar hai, toh naye number ko `min_stack` mein bhi append kar diya jata hai.
* `else: self.min_stack.append(self.min_stack[-1])` (Duplication Logic):
  - Agar naya number chota nahi hai, toh purana minimum hi dobara `min_stack` mein daal diya jata hai. Iska maqsad yeh hota hai ke dono stacks ka size hamesha barabar (synchronized) rahe, taaki baad mein `pop()` ke waqt koi galti na ho.

**Step 2 (Pop Method - Safe Removal):** 
* Jab hum `obj.pop()` chalate hain, toh stack ka aakhri element hatana hota hai.
* Kyunki humne `min_stack` ka size main stack ke barabar rakha tha, isliye hum dono se ek sath pop karte hain: `self.stack.pop()` aur `self.min_stack.pop()`.
* Is tarah jab main stack se bada number udta hai, toh `min_stack` bhi apna duplicate hata deta hai aur bilkul sahi waqt par purana minimum wapas top par aa jata hai.

**Step 3 (Top Method - Inspecting Last Element):** 
* `def top(self) -> int:` function bina kisi element ko remove kiye, sirf main stack ka aakhri element dekhne ke liye `self.stack[-1]` return karta hai.

**Step 4 (GetMin Method - O(1) Minimum Retrieval):** 
* `def getMin(self) -> int:` function `min_stack` ka aakhri element `self.min_stack[-1]` return karta hai.
* Kyunki `min_stack` ka top hamesha current minimum par hota hai, isliye yeh operation bina poore stack ko loop kiye bilkul foran ($O(1)$ time mein) minimum bata deta hai.
