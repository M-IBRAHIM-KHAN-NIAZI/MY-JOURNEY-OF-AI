### Movement Logic Summary with Example (Remove K Digits - LC 402) ###

**Example Input:** `num = "12345"`, `k = 2` $\rightarrow$ Output: `"123"`.

**Step 0 (Setup & Stack Initialization):**
* `stack = []`: Ek khali list banati hai jo digits ko **increasing order** (chote se bare) mein rakhti hai taaki shuru (left side) mein sabse chote digits aa sakein.
* `k`: Utne digits ki ginti jo remove karne hain taaki final number sabse chota bane.

**Step 1 (Iterating Left to Right - For Loop):**
* `for digit in num:`: String `num` ke har digit ko left se right uthata hai kyunke left side ke digits ki place value sabse zyada hoti hai.
* Shuru mein (`digit = '1'`, `k = 2`) `stack` khali hota hai, isliye `while` condition false rehti hai aur `'1'` seedha stack mein chala jata hai (`stack = ['1']`).

**Step 2 (Dropping Taller Left Digits - While Loop):**
* `while stack and k > 0 and digit < stack[-1]:`:
  - `stack` check karta hai ke stack khali na ho.
  - `k > 0` check karta hai ke abhi digits remove karne ki gunjaish baaki ho.
  - `digit < stack[-1]` check karta hai ke kya current digit, stack ke top (`stack[-1]`) wale digit se **chota** hai.
  - Jaise hi chota digit milta hai, stack ke top par maujood bara digit (`stack.pop()`) hata diya jata hai aur `k -= 1` kar diya jata hai.
  - *(Example: `num = "12345"`, `k = 2` mein `'2' < '1'`, `'3' < '2'`, `'4' < '3'`, `'5' < '4'` sab false rehte hain kyunke digits pehle se increasing hain—isliye `while` loop ek baar bhi nahi chalta aur `stack = ['1', '2', '3', '4', '5']` banta hai).*

**Step 3 (Pushing Current Digit):**
* `stack.append(digit)`: Jab `while` loop ruk jata hai, tab current `digit` stack mein push hota hai taaki increasing order barkarar rahe.

**Step 4 (Remaining `k` Slice, Leading Zeros & Return):**
* `if k > 0: stack = stack[:-k]`: Agar loop khatam hone ke baad bhi `k > 0` bacha ho, toh aakhir se `k` digits kaat diye jaate hain kyunke increasing order mein end wale digits sabse kam nuksaan dete hain. *(Example: `k = 2` bacha hai $\rightarrow$ `stack[:-2]` se `'4'` aur `'5'` hate, `stack = ['1', '2', '3']`).*
* `result = "".join(stack).lstrip("0")`: Digits ko jor kar string banata hai aur shuru ke saare leading zeros hata deta hai.
* `return result if result else "0"`: Final non-empty string return karta hai, ya sab kuch hatne par `"0"` return karta hai. *(Example: `"".join(['1', '2', '3']).lstrip("0")` $\rightarrow$ **`"123"`**).*
