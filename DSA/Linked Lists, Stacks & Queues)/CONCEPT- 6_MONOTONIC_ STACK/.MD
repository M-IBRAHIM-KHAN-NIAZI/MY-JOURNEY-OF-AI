1. Simple Way Mein: Monotonic Stack Kya Hai?
Soch le Monotonic Stack ek aisa stack (list) hai jisme hum items ko ek discipline / rule ke saath rakhte hain—ya to barhte order mein (chote se bada) ya ghatte order mein (bade se chota).

Jab bhi naya item aata hai:

Agar woh naya item stack ke rule ko torhta hai, toh jo purane items us rule ke hisaab se peeche/neeche reh gaye hain, unhein bahar nikal diya jata hai (pop).

Uske baad naya item stack mein daal diya jata hai (append).

Asal fayda: Humein har baar peeche jaakar sab kuch dobara scan nahi karna parta. Jo kaam ka nahi rehta ya jiska jawab mil jata hai, woh wahin nikal jata hai.

# Width Rule (when both left_boundary and i are outside/blocking bars):
# width = i - left_boundary - 1 (i idr right ko represent karaha ha or left boundary left ko)
# - Dono boundaries andar shamil hon -> right - left + 1
# - Sirf ek boundary andar ho -> right - left
# - Dono boundaries bahar (rukawat) hon -> i - left_boundary - 1

Hum Kaise Pata Karein Ke Kaun Si Boundary Andar Hai Aur Kaun Si Bahar?
Problem ki statement aur condition dekho ke jis index par tum ho (left ya right), kya woh valid / allowed hai ya invalid / rukawat hai:Kab BAHAR (exclude) hoti hai?
Jab wo index condition tod raha ho ya rukawat ho.LC 84 (Histogram) mein: i par height choti ho gayi, isliye i par rectangle nahi ban sakta (i bahar). Aur left_boundary (stack[-1]) wali bar bhi choti hai, isliye rectangle uske aage left_boundary + 1 se shuru hota hai (left_boundary bhi bahar). Dono bahar $\rightarrow$ i - left_boundary - 1.
Kab ANDAR (include) hoti hai?
Jab left aur right dono valid positions hon jinhe hum range mein shamil kar rahe hain.Jaise array ke left se right tak saare elements ginne hon $\rightarrow$ dono andar $\rightarrow$ right - left + 1.
Kab EK ANDAR aur EK BAHAR hoti hai?
Jab ek index shamil ho aur doosra shamil na ho.Jaise Python slice arr[left:right] mein left andar hota hai aur right bahar (stop index) hota hai $\rightarrow$ right - left.

# Python `.lstrip()` — Role & Behavior (LC 402 Note)

* **Kya Karta Hai (`lstrip` = Left Strip):**
  String ke bilkul **shuru (left side)** se diye gaye characters ko lagatar hata kar naya string return karta hai.
* **Kab Rukta Hai:**
  Jaise hi left side se pehla aisa character mil jata hai jo hatane wale characters mein shamil nahi hai, `.lstrip()` **wahin ruk jata hai** — beech ya aakhir (right) ke characters ko bilkul nahi chherta.
* **Kitni Baar Hatata Hai:**
  Ek baar nahi, balki **shuru mein jitni baar bhi lagatar** aaye, sab hata deta hai:
  * `"0200".lstrip("0")` $\rightarrow$ `"200"`
  * `"000200".lstrip("0")` $\rightarrow$ `"200"`
  * `"002000".lstrip("0")` $\rightarrow$ `"2000"` *(end ke zeros bach gaye)*
  * `"000".lstrip("0")` $\rightarrow$ `""` *(empty string)*
* **LC 402 Mein Role:**
  `"".join(stack)` digits ko ek string mein jorta hai, aur `.lstrip("0")` shuru ke faltu leading zeros hata deta hai (`"0200"` $\rightarrow$ `"200"`). Agar sab kuch hat kar `""` bache, toh `result if result else "0"` aakhir mein `"0"` return kar deta hai.
* **Bonus Yaad Rakhne Wali Baatein:**
  * `.lstrip("0")` = sirf **left** se hatata hai.
  * `.rstrip("0")` = sirf **right** se hatata hai.
  * `.strip("0")` = **dono taraf** (`left` aur `right`) se hatata hai.
  * `lstrip("abc")` = poora shabd nahi balki **character set** hai (`'a'`, `'b'`, `'c'` mein se jo bhi shuru mein milega, hatata rahega).
