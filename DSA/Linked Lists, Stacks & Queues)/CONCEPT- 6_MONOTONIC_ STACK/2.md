### Movement Logic Summary with Example (Largest Rectangle in Histogram - LC 84) ###

**Example Input:** `heights = [2, 1, 5, 6, 2, 3]` $\rightarrow$ Output: `10`.

**Step 0 (Setup & Sentinel Initialization):**
* `stack = []`: Ek khali list banati hai jo **bars ke indices (`0, 1, 2...`)** store karti hai (heights nahi), aur unki heights ko **increasing order** (choti se bari) mein rakhti hai.
* `max_area = 0`: Ab tak ka sabse bara rectangle area save karne ke liye `0` se shuru hota hai.
* `heights_ext = heights + [0]`: List ke aakhir mein ek **Sentinel `0`** jora jata hai (`[2, 1, 5, 6, 2, 3, 0]`) taaki loop ke end mein stack ke andar bachi hui saari bars bhi `0` se bari hone ki wajah se pop ho jayein aur kisi ka area calculate hone se reh na jaye.

**Step 1 (Iterating Left to Right - For Loop):**
* `for i, h in enumerate(heights_ext):`: Har index `i` aur uski current bar height `h` ko left se right uthata hai.
* Shuru mein (`i = 0, h = 2`) `stack` khali hota hai, isliye `while` condition false rehti hai aur index `0` seedha stack mein chala jata hai (`stack = [0]`).

**Step 2 (Right Boundary Hit & Popping Taller Bars - While Loop):**
* `while stack and h < heights_ext[stack[-1]]:`:
  - `stack` check karta hai ke peeche koi bar wait kar rahi hai ya nahi.
  - `h < heights_ext[stack[-1]]` check karta hai ke kya current bar ki height `h`, stack ke top (`stack[-1]`) wale index ki height se **choti** hai (`stack[-1]` index hai, isliye `heights_ext[stack[-1]]` se uski asal height nikalti hai).
  - Jaise hi choti height `h` milti hai, stack ke top par maujood badi bar ka right side expansion yahin ruk jata hai (right boundary mil gayi).
  - `mid_idx = stack.pop()`: Us badi bar ka index stack se bahar nikala jata hai.
  - `bar_height = heights_ext[mid_idx]`: Us nikle hue index ki asal height li jati hai jo rectangle ki height banegi.
  - `left_boundary = stack[-1] if stack else -1`: Pop karne ke baad stack ke top par jo bar bachti hai woh left side ki rukawat (left boundary) hai; agar stack khali ho jaye toh left mein koi rukawat nahi isliye `-1` liya jata hai.
  - `width = i - left_boundary - 1`: Right rukawat `i` aur left rukawat `left_boundary` ke beech jitni bars aati hain unki width nikali jati hai.
  - `area = bar_height * width`: Area calculate hota hai aur `max_area` se bara hone par update kar diya jata hai.
  - Yeh `while` loop tab tak chalta rehta hai jab tak stack khali na ho jaye ya top par `h` se choti/barabar bar na aa jaye. *(Example: `i = 4, h = 2` par pehle index `3` (`6`) pop hota hai $\rightarrow$ `width = 4 - 2 - 1 = 1, area = 6`, phir index `2` (`5`) pop hota hai $\rightarrow$ `width = 4 - 1 - 1 = 2, area = 10`, phir index `1` (`1`) par `2 < 1` false hone se loop rukta hai).*

**Step 3 (Pushing Current Index & Final Return):**
* `stack.append(i)`: Jab `while` loop poora khatam ho jata hai (saari badi bars pop ho chuki hoti hain), tab current bar ka index `i` stack mein push hota hai taaki stack ka increasing order barkarar rahe.
* Aakhir mein sentinel `0` (`i = 6, h = 0`) bachi hui bars (`3`, `2`, `1`) ko pop karke unke areas (`3`, `8`, `6`) check karta hai, aur loop khatam hone par `return max_area` se **`10`** return ho jata hai.
