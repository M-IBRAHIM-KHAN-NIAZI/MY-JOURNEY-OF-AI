### Movement Logic Summary with Example (Sliding Window Maximum - LC 239) ###

**Example Input:** `nums = [1, 3, -1, -3, 5, 3, 6, 7]`, `k = 3` $\rightarrow$ Output: `[3, 3, 5, 5, 6, 7]`.

**Step 0 (Setup & Deque Initialization):**
* `dq = deque()`: Ek double-ended queue banati hai jo **indices** ko aise order mein rakhti hai ke unki values **decreasing (bare se chote)** hon, taaki front (`dq[0]`) hamesha current window ka sabse bara element rahe.
* `result = []`: Ek khali list banati hai jo har complete `k`-size window ke maximum element ko store karti hai.

**Step 1 (Iterating Left to Right - For Loop):**
* `for i in range(len(nums)):`: Array `nums` ke har index `i` ko `0` se `len(nums) - 1` tak left se right move karta hai jaise `k`-size ki window aage slide kar rahi ho.
* *(Example: `k = 3` ke saath pehli poori window `i >= 2` par banegi aur expired boundary `i - 3` hogi).*

**Step 2 (Removing Expired Indices From Front - If Condition):**
* `if dq and dq[0] <= i - k:`:
  - `dq` check karta hai ke deque khali na ho.
  - `dq[0] <= i - k` check karta hai ke front (`dq[0]`) par rakha purana index current window `[i - k + 1, i]` se bahar toh nahi nikal gaya.
  - Jaise hi purana index expire hota hai, `dq.popleft()` se usay left/front side se hata diya jata hai.
  - *(Example: `i = 3` (`-3`) par `i - k = 0` hota hai; index `0` (`1`) `0 <= 0` hone ki wajah se front se `popleft()` ho jata hai).*

**Step 3 (Dropping Smaller or Equal Elements From Back - While Loop):**
* `while dq and nums[dq[-1]] <= nums[i]:`:
  - `dq` check karta hai ke deque khali na ho.
  - `nums[dq[-1]] <= nums[i]` check karta hai ke deque ke back (`dq[-1]`) wale index ki value current `nums[i]` se **kam ya barabar** toh nahi.
  - Jo elements chote ya barabar hote hain, unhe `dq.pop()` se back se hata diya jata hai kyunke naya bara element `nums[i]` aage rehte hue unhe kabhi maximum nahi banne dega.
  - *(Example: `i = 4` (`5`) aane par piche ke `-3` aur `-1` ke indices `pop()` ho jaate hain; `i = 6` (`6`) aane par `3` aur `5` ke indices `pop()` ho jaate hain).*

**Step 4 (Appending Current Index & Recording Window Max):**
* `dq.append(i)`: Current index `i` ko deque ke back mein push karta hai taaki `dq` mein values ka decreasing order barkarar rahe.
* `if i >= k - 1: result.append(nums[dq[0]])`: Jab `k` elements ki poori window ban jati hai (`i >= 2`), tab front wale sabse bare element `nums[dq[0]]` ko `result` mein append kar diya jata hai.
* *(Example: `i = 2` par `3`, `i = 3` par `3`, `i = 4` par `5`, `i = 5` par `5`, `i = 6` par `6`, aur `i = 7` par `7` add hota hai).*

**Step 5 (Return Result):**
* `return result`: Poore array par window slide karne ke baad final list `[3, 3, 5, 5, 6, 7]` return kar deta hai.
