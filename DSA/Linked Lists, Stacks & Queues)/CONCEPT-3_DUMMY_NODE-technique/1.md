1. Asal Problem Kya Hai? (Kyun zaroorat padti hai?)
Jab hum koi aisi problem solve karte hain jahan hamein zero se ek nayi Linked List khadi karni pade (misal ke tor par: do sorted lists ko apas mein merge karna, ya kuch specific numbers filter karke nayi list banana):

Sabse bada sawal yeh hota hai ke "Nayi list ka Head (pehla dabba) kahan se laayein?"

Agar hum pehle dabbe ko seedha Head maan lein, aur kal ko wahi dabba delete ho jaye ya badal jaye, toh hamara poora reference hil jata hai aur code mein bugs aa jate hain.

2. Dummy Node Asal Mein Kya Hai? (The Solution)
Dummy node ek farzi (placeholder) dabba hota hai (jaise ListNode(0) ya -1), jiska data hamare kisi kaam ka nahi hota.

Iska ek hi maqsad hota hai: Ek permanent anchor ya starting base dena taake humein kabhi yeh sochna na pade ke head kahan hai. Hum isko hamesha nayi list ke bilkul shuru mein rakh dete hain.
