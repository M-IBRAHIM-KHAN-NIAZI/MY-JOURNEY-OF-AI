### Movement Logic Summary (Example: 1 -> 2 -> 3 -> 4 -> 5, n = 2)

- **Step 1 (Setup):** `dummy`, `slow`, aur `fast` teeno ko start mein dummy node par rakhte hain. List: `dummy -> 1 -> 2 -> 3 -> 4 -> 5`.
- **Step 2 (Gap Creation):** `for` loop se `fast` ko `n + 1` (yani `2 + 1 = 3`) steps aage bhejte hain. Ab `fast` dabba `3` par chala jata hai, aur `slow` dummy par rehta hai (dono ke beech fixed gap ban jata hai).
- **Step 3 (Moving Together):** `while` loop chalate hain jo tab tak chalta hai jab tak `fast` `None` (end) tak na pahunch jaye:
  - Jab `fast` `4` par jata hai $\rightarrow$ `slow` `1` par jata hai.
  - Jab `fast` `5` par jata hai $\rightarrow$ `slow` `2` par jata hai.
  - Jab `fast` `None` par jata hai $\rightarrow$ `slow` `3` par ruk jata hai.
- **Step 4 (Deletion):** `slow` ab theek delete hone wale node (`4`) se ek step pehle (`3`) par khada hai. Code `slow.next = slow.next.next` chala kar `4` ko bypass (delete) kar deta hai!
