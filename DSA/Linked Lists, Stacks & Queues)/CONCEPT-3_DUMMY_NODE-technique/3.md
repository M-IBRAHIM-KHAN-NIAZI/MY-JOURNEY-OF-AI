### LeetCode 86: Partition List - Complete Logic & Pointer Summary

- **Step 1 (Setup & Dummies):** Do farzi nodes (`less_dummy` aur `greater_dummy`) banate hain. `less` aur `greater` pointers ko in par rakhte hain, aur `current` pointer ko original list ke `head` par set karte hain.
- **Step 2 (Traversal & Splitting Loop):** Ek `while current is not None` loop chalate hain jo poori list ko ek-ek node karke scan karta hai:
  - Agar `current.value < x` hai, toh node ko `less` list mein jodh dete hain (`less.next = current`) aur `less` pointer ko aage khiska dete hain (`less = less.next`).
  - Agar value badi ya barabar hai, toh node ko `greater` list mein jodh dete hain (`greater.next = current`) aur `greater` pointer ko aage khiska dete hain (`greater = greater.next`).
  - Har baar `current = current.next` karke original list mein ek step aage badh jate hain.
- **Step 3 (Cycle Prevention):** Badi list ke aakhir mein infinite loop ya cycle se bachne ke liye `greater.next = None` set kar dena bohot zaroori hota hai.
- **Step 4 (Merging Lists):** Choti list ke aakhir (`less.next`) ko badi list ke pehle node (`greater_dummy.next`) se jodh dete hain taake dono lists mil kar ek ho jayein.
- **Step 5 (Final Return):** `less_dummy.next` return kar dete hain jo hamari nayi partitioned list ka actual head hota hai.

### 🔍 Deep Dive: Pointers, Dummies aur unki Galat Jagah Use Karne ka Asar

- **`less` vs `less_dummy`:** 
  - `less_dummy` ek **fixed starting anchor** hai jo hamesha list ke bilkul shuru mein apni jagah fix rehta hai taake aakhir mein hum wahan se poori list return kar sakein (`return less_dummy.next`).
  - `less` ek **moving pointer** hai jo loop ke chalte-chalte choti list ke **bilkul aakhir (tail)** par pahunch jata hai.
- **`greater_dummy.next` vs `greater.next`:**
  - `greater.next` aakhir mein `None` ho chuka hota hai (cycle prevent karne ke liye), isliye agar hum `less.next = greater.next` likhein toh choti list ke aage `None` jud jayega aur poori greater list beech raste mein gayab ho jayegi.
  - `greater_dummy.next` badi list ka **pehla node (head)** deta hai, jisse woh pehla node judne par poori ki poori greater list automatically sath jud jati hai.
- **Agar `less.next` ki jagah `less_dummy.next` use kar liya jaye:**
  - Agar hum galti se `less_dummy.next = greater_dummy.next` likh dein, toh choti list ka pehla node aur uske **saare elements over-write hokar disconnect aur gayab** ho jayenge. 
  - Isliye hamesha aakhri pointer (`less.next`) par hi badi list jodi jati hai taake pehli list ke saare elements aur head bilkul safe rahein!
