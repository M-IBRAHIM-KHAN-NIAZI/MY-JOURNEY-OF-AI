# Recursion (A-to-Z Quick Note)

- **Kya Hai:** Jab koi function khud ko chote input ke saath call karta hai jab tak jawab seedha na mil jaye.
- **Base Case:** Rukne ki shart (`if`) jo infinite calls aur `RecursionError` ko rokti hai.
- **Recursive / Shrink Step:** Har call mein input ko chota karna (`n - 1`, agla node, adha size, etc.) taaki base case tak pahunche.
- **Call Stack (Going Down & Unwinding):** Calls stack mein push hoti hain, base case pe rukti hain, aur wapas aate waqt (`return`) result banti hain.
- **Complexity Rule:** Time = `(calls) * (per-call work)`, Space = kam se kam `O(recursion depth)`; repeat calls hon toh memoization lagao.
### Example: Factorial (`factorial(3)`)
```python
def factorial(n):
    if n == 1:          # Base Case: yahan rukna hai
        return 1
    return n * factorial(n - 1)   # Shrink Step: problem choti ki

Going Down (Stack Push):

factorial(3) -> waits for 3 * factorial(2)

factorial(2) -> waits for 2 * factorial(1)

factorial(1) -> Base case hit! Returns 1

Unwinding (Stack Pop & Final Result):

factorial(2) gets 2 * 1 -> returns 2

factorial(3) gets 3 * 2 -> returns 6

- **Direction of Start & Base Case:** Step kam (`- 1`) ya zyada (`+ 1`) hona is baat par depend karta hai ke tum kahan se start kar rahe ho aur base case kahan hai—agar base case `1` hai aur start `3` se hai toh `n - 1` karke neeche jaate hain, aur agar base case `5` hai aur start `1` se hai toh `n + 1` karke upar jaate hain taake har step base condition ke kareeb pahunch sake.
- **Role of Recursive Call vs `return`:** Asli repeat `return` keyword ki wajah se nahi balkay uske andar likhi **recursive function call** (`factorial(n - 1)` ya `n + 1` wali call) ki wajah se hota hai, jo naye inputs ke saath calls chalati rehti hai jab tak base condition true na ho jaye, aur phir `return` us result ko wapas bhejta hai.
