Humein do numbers diye jaate hain: ek base number x (decimal/float bhi ho sakta hai) aur ek power n (positive, negative, ya zero integer). Humein $x^n$ calculate karna hai.
Simple Logic (Fast Power / Divide & Conquer):Agar hum x ko n baar multiply karein ($2 \times 2 \times 2 \dots$), toh agar n bohat bara ho (2,000,000,000), toh loop bohat slow chalega (O(n)).Isliye hum power ko har step mein aadha (n // 2) karte hain:
### Problem Logic & Rules (Pow(x, n) - LC 50)

- **Problem Statement:**
  - Humein base `x` aur power `n` di jaati hai, aur `x^n` nikalna hai.

- **Fast Power Logic (Divide & Conquer):**
  - Loop se `x` ko `n` baar multiply karna slow hai (`O(n)`).
  - Isliye har step mein power ko aadha (`n // 2`) karte hain (`O(log n)`).
  - **Agar `n` even hai:** `x^n = x^(n/2) * x^(n/2)` (jaise `2^4 = 2^2 * 2^2`).
  - **Agar `n` odd hai:** `x^n = x * x^(n/2) * x^(n/2)` (jaise `2^5 = 2 * 2^2 * 2^2`).
  - **Agar `n` negative hai:** `x^(-n) = 1 / x^n` (jaise `2^-2 = 1 / 2^2`), isliye `x = 1 / x` aur `n = -n` karte hain.
### Movement Logic Summary with Example (Pow(x, n) - LC 50)

- **Setup (Negative Exponent):**
  - Agar `n < 0` ho, toh `x` ko `1 / x` aur `n` ko `-n` bana dete hain.
  - Iske baad recursion normal positive power ki tarah chalta hai.

- **Downward Movement (Call Chain):**
  - Har call `n` ko `n // 2` karke chota karti jaati hai.
  - Apni `half` calculation rok kar rakhti hai jab tak `n == 0` na aaye.

- **Turnaround Point (Base Case):**
  - Jab `n == 0` hit hota hai, toh neeche jaana rukta hai.
  - Yahan se seedha `1` return hota hai.

- **Upward Movement (Unwinding):**
  - Neeche se aata hua `half` har call ke apne `n` ke hisaab se solve hota hai.
  - Agar `n` even hai toh `half * half`, agar odd hai toh `x * half * half`.

- **Example (`x = 2, n = -3`):**
  - **Setup:** `n < 0` -> `x = 1 / 2` (`0.5`), `n = 3`.
  - **Downward:**
    - `helper(0.5, 3)` waits for `helper(0.5, 1)`
    - `helper(0.5, 1)` waits for `helper(0.5, 0)`
    - `helper(0.5, 0)` hits base case -> returns `1`
  - **Upward (Unwinding):**
    - `helper(0.5, 1)` (`n = 1` odd) -> `0.5 * 1 * 1 = 0.5`
    - `helper(0.5, 3)` (`n = 3` odd) -> `0.5 * 0.5 * 0.5 = 0.125`
    - Final answer: `0.125` (`1 / 8`)
